Date: 12 November 2026. Run id: 20261112T130340Z_ugv_strapdown_s00_72821b0c. Code: commit `72821b0`.
Figure: `results/figures/kitti_2011_09_30_drive_0016_strapdown.png`, with the run

Purpose: a first check of the data path and of the conventions of
`docs/interfaces.md` on real data. This is not a performance result.

## Configuration

KITTI raw `2011_09_30_drive_0016` (extract). Inertial input: `wx wy wz ax ay az` only.
Oracle initial state (position, velocity, orientation from the reference at the first
sample), zero initial bias estimate, no measurement update, zero-order-hold
integration. 2967 samples, 29.659 s, reference path length 416.15 m. One segment, no
timestamp gap.

## Vertical channel

The vertical error grows with the square of time; the equivalent constant acceleration
error is -0.0091 m/s^2. The reference is not consistent with itself in the vertical
direction: its altitude changes by -0.11 m over the drive, while the integral of its
own vertical velocity is -2.83 m. The strapdown estimate changes by -4.13 m.

The mean accelerometer norm is 9.8119 m/s^2 and the gravity magnitude used is
9.81 m/s^2. This difference would move the estimate upwards (about +0.8 m), opposite
to the observed error, and does not explain it.

OPEN: which part of the vertical error belongs to the integration and which to the
reference altitude cannot be separated with this drive.

## What this run supports

The data path, the frame definitions, the quaternion convention and the reference
orientation mapping are consistent on real data: a sign or axis error would produce a
horizontal error of tens of metres.

## What this run does not support

- The horizontal error is of the same order as the position accuracy reported by the
  reference (0.10 to 0.155 m). No finer statement is made.
- The inertial channels and the reference come from the same OXTS unit, and the
  channels may be corrected by its internal filter (OPEN in the contract). The low
  horizontal drift is not attributed to sensor quality or to the method.
- The drive is close to straight and has no stop: nothing is said about turns,
  zero-velocity updates or long outages.
- The initial state is taken from the reference: this is not evidence of operational
  GNSS-denied navigation.
- The zero-order-hold integration has an error of first order in the step (0.31 m over
  a 300 m circle at 100 Hz with exact synthetic measurements).
